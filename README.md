# 多人时间表

一个用来算「全员共同空闲时段」的练习项目。

## 跑起来（骨架阶段）

前置：Node.js（本机默认的 v22 即可）

```bash
cd frontend
npm install
npm run dev
```

终端会显示一个本地地址（通常是 http://localhost:5173/），用浏览器打开它。

注意：`npm run dev` 会一直占着这个终端窗口，别关；要停服务按 Ctrl+C。

## 怎么算跑对了

页面上应出现：

- 一行说明：`2026-11-15 · 2 人 · 最短 30 分钟 · 缓冲 15 分钟`
- 两段空闲：`08:00 – 08:45（45 分钟）`、`12:15 – 22:00（585 分钟）`

## 现在的数据从哪来

`shared/mock/` 里的假响应。后端接口还没实现，骨架阶段**不用启动 backend/**。

前端读的是 Mock 文件，不是真接口。等后端写好，把 `frontend/src/main.js`
顶部的 `DATA_SOURCE` 从 Mock 路径换成 `/api/free-slots` 即可，页面其余代码不用动。

## 目录

- `shared/` — 接口契约 + Mock 数据，前后端共用同一份，别复制
- `frontend/` — 页面（vite）
- `backend/` — 接口（骨架阶段还没实现）

## 规则速览

- 共同空闲 = 可安排范围 − 全员忙碌时段的并集
- 默认范围 08:00–22:00，最短可用 30 分钟，忙碌块前后各留 15 分钟缓冲
- 详细规则见 `需求表.md` 和 `shared/types.ts`
